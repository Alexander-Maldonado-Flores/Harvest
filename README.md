Harvest

Harvest is a personal finance and savings management application designed to help users organise their money, manage savings buckets, track financial goals and understand their future finances.

Project Structure
mobile/ – React Native / Expo mobile application.
backend/ – Python Flask API and database services.
docs/ – Project documentation.
Technology Stack
Mobile: React Native and Expo
Backend: Python and Flask
Database: SQLite (initial development)
Project Status

Project structure established. Application development and implementation are in progress.
